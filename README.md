# Task 1 — Authentication Foundation

MVC scaffold + User auth (register, login with Remember Me, logout, profile view/edit).

## Run
1. Place this `Task1/` folder in `xampp/htdocs/`.
2. Run DB setup ONCE from any task (shared DB): `http://localhost/Task1/setup_db.php`
3. Open: `http://localhost/Task1/`

## Contains
- `models/User.php`
- `controllers/`: AuthController, HomeController, ProfileController
- `views/`: auth, profile, home, layout
